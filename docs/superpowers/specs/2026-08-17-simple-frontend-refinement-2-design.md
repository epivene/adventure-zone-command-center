# Simple Frontend Refinement 2 Design

Goal: reduce remaining surface-level intimidation after the first frontend refinement, without removing any tools.

Approved direction carried forward:
- Today uses one compact Needs Attention list instead of summary cards.
- Secondary Today labels use plain language.
- Follow-up edit/delete tools live under a More menu.
- Profile active filter chips are individually removable.
- Profile sheet avoids repeating the profile name and tucks low-value counts/details under More profile details.
- Open follow-ups appear in Notes and in History filtering.
- Calendar selects today in the current month and hides imported ACT activity under More.
