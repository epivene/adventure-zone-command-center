# RMAF online directory import

Source: the public RMAF fair/festival and service-member directories, retrieved September 10, 2026.

The seed contains 285 public listings (135 fair/festival members and 150 service members). Eighty fair/festival detail pages were available during retrieval and their published descriptions, emails, phones, websites, and locations are retained in `facts`. Every record keeps its public profile URL as the source identity.

The migration creates or matches CRM organizations and contacts, adds a dated source note, and links RMAF 2026 convention cards when the identity is safe. New cards are marked `association_only` because directory membership does not prove convention attendance. It sends no messages and creates no bookings.
