## Extraction notes

- The source uses a calm operational CRM composition rather than a social-profile
  layout: record identity, relationship status, rating, website, compact metadata,
  metrics, next action, relationship health, and recent history.
- The dominant light surfaces are `#f3f5f0` and `#fbfcf8`, with deep
  blue-green text `#173b48`, emerald primary actions `#397064`, and terracotta
  attention accents `#d4874f`.
- The source's UI face is DM Sans in the modern profile treatment; Geist Mono is
  retained for compact technical values and metadata.
- No standalone source logo asset was present in the selected mockup, so no logo
  asset is invented or retained in this system.
- The selected source has no documented dark theme. The dark token set is a
  derived companion theme, checked for contrast and palette coherence.
