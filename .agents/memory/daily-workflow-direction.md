name: Daily workflow direction
description: User-approved scope and layout direction for simplifying daily CRM work.
---

The user chose Today, leads, and booking follow-up as the first redesign area and approved a unified selectable work queue with the selected record's next step alongside it. The user now wants the simplification and visual direction extended across the whole CRM, not left as isolated screen fixes.

**Why:** The user said the app has redundant buttons and that its overall layout and flow need simplification, then clarified the entire app still needs a coordinated makeover to work better as a CRM.

**How to apply:** Extend the existing “one next step” direction consistently across owner, office, Boss, and manager workflows. Keep actions contextual and repeated data in one place, while preserving each role's permissions and keeping legacy CRM capabilities reachable. Design and implement in stages rather than replacing every workspace at once.

Keep frequent destinations, especially Profiles, visibly discoverable rather than hiding all navigation inside a workspace dropdown. Clickable preview navigation must show distinct destination content, not just change a label while leaving Today on screen.

**Why:** The user said Profiles was difficult to find and reported that clicking other pages still showed Today in the whole-CRM preview.

**How to apply:** Reduce duplicate navigation without removing the primary navigation. Demonstrate actual screen transitions for the modeled routes; clearly identify any destination not yet modeled.
