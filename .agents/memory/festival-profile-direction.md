---
name: Festival profile direction
description: User-chosen organizer versus event-edition ownership and preservation scope.
---

Keep existing organizer and contact information, bookings, and CRM history. Add missing FestivalNet-style information rather than replacing existing records. Shared organizer facts remain on the organizer; changing schedules, deadlines, fees, requirements, and other annual facts belong to the event edition.

**Why:** The user wants the breadth of FestivalNet's sample event profile while keeping everything already in the CRM, and explicitly chose shared organizer details plus event-edition details.

The user approved both the festival-profile layout and the Today-style Leads layout with visible suggested-leg assignments for integration into the app.

**How to apply:** Treat new event fields as optional, preserve existing values and relationships, and apply the simpler Today interaction direction. Leads and suggested-leg assignments are the next area after profiles.

Do not silently combine or overwrite two organizers' saved edition records for the same year during a duplicate-profile merge.

**Why:** The user requires existing CRM information to be preserved; choosing one annual record or merging conflicting text automatically can lose information.

**How to apply:** Reparent distinct years inside the existing merge transaction. Block overlapping years before deletion and require reconciliation.

Profiles should have fewer buttons and separate pages; combine related information, and show the newest note and newest linked profile email front and center. The email must link to that conversation in the app's Emails workspace.

**Why:** The user explicitly requested this simplification after using the expanded profiles.

**How to apply:** Keep all existing records and actions, avoid repeated summary and action surfaces, and put the latest actual note ahead of secondary profile tools.

The user prefers importing FestivalNet PDFs instead of spreadsheet exports.

**Why:** The user said PDFs are cheaper for them.

**How to apply:** Make PDFs a supported primary FestivalNet import format; do not require an Excel or CSV export.
